# Stage 1 · Plan — `intent.md`

One file per intent: `intent/<slug>.md`. Template and full stage description:
[`hallo-theo/.github/sdlc`](https://github.com/hallo-theo/.github/tree/main/sdlc).

Written by whoever had the idea — **you do not need to be an engineer.**
Describe the problem, not a solution: problem · proposed outcome · affected
users and systems · constraints · open questions.

**No personal data.** No tenant or owner names, addresses, IBANs, emails or
phone numbers, including in pasted text and examples. Git history is immutable
and is copied into every clone and every agent session. Use an object ID or
"a tenant in Berlin". This is GDPR-load-bearing.
