# Stage 2 · Design — `spec.md`

One file per change: `spec/<slug>.md`. Template:
[`hallo-theo/.github/sdlc`](https://github.com/hallo-theo/.github/tree/main/sdlc).

Must state **how the change will be verified** — a spec without that is not
done — and must flag its own concerns, especially where two policies
contradict. Concerns get resolved with the policy owner *before* engineering
starts.

Same no-personal-data rule as `intent/`.
